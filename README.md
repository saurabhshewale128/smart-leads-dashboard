# Smart Leads Dashboard

A full-stack MERN CRM dashboard application.

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB

## Features
- User Authentication
- Add Leads
- View Leads
- Dashboard Analytics
- Responsive UI
